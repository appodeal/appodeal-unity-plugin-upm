# Documentation map

## For people who use the plugin

- [README.md](../README.md): links to the public docs, the sample and support.
- [Documentation~/Index.md](../Documentation~/Index.md): the page Unity shows in
  the Package Manager. It ships with the package.
- [CHANGELOG.md](../CHANGELOG.md): release notes, generated by release-it.
- [Third Party Notices.md](../Third%20Party%20Notices.md) and
  [LICENSE.md](../LICENSE.md).

## For contributors

- [AGENTS.md](../AGENTS.md): commands, repo map, conventions and restricted
  files. CLAUDE.md only imports it.
- [CONTEXT.md](../CONTEXT.md): glossary of ad and build terms.
- [dev-flow.md](dev-flow.md): from a Jira ticket to a tagged release.
- [adr/](adr/): architecture decision records, start from
  [adr/\_template.md](adr/_template.md).
- [.agents/skills/](../.agents/skills/): step-by-step procedures for agents and
  people: preparing a release, updating native dependencies.
- [.github/workflows/ci.yml](../.github/workflows/ci.yml): what CI checks on
  every PR.
- [.github/workflows/release.yml](../.github/workflows/release.yml): drafts the
  GitHub release after a release PR is merged into `main`.

None of these files except `Documentation~/` reach the users: `.npmignore`
excludes them from the package.
